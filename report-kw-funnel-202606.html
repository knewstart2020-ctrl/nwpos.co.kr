3. 전략 ① — 싼 키워드로 유입, 상담에서 전 제품 제안

전무님 아이디어가 정확합니다. 데이터가 이렇게 말합니다:

· 포스기에 직접 광고 = 체결 1건당 광고비 347만~478만원
· 테이블오더에 직접 광고 = 체결 1건당 920만~1,100만원
· 네이버단말기로 유입 = 체결 1건당 17만원 · 토스단말기 = 67만원

핵심 논리: 토스단말기·네이버단말기를 검색하는 사람도 결국 매장 사장님입니다. 싸게(953~3,996원) 우리 사이트로 모셔온 뒤, 상담 전화 한 통에서 포스·테이블오더·키오스크까지 전 라인업을 함께 제안하면 됩니다.

  • 같은 사장님을 포스기 광고로 만나면 2.5만원, 네이버단말기 광고로 만나면 1천원 — 20배 이상 저렴하게 같은 고객을 만납니다.
  • 상담은 어차피 사람이 합니다. 들어온 문의에 "포스도 보시겠어요?" 한마디면 교차 제안 끝.
  • 랜딩·상담 멘트에 "단말기 + 포스 + 테이블오더 묶음 상담"을 넣어 자연스럽게 연결.

4. 전략 ② — 젊은 사장님은 '토스·네이버단말기'로 들어온다

검색량이 말해줍니다. 토스단말기 11,090(전 키워드 최다) · 네이버단말기 2,330. 토스페이·네이버페이는 디지털에 익숙하고 수수료에 민감한 젊은·신규 창업 사장님이 먼저 찾는 간편결제입니다.

젊은·신규 사장님의 입구

토스단말기·네이버단말기 — 간편·저렴·트렌디. 검색량 많고 광고비 싸다(가성비 최고). 이들을 먼저 잡는다.

전환 후 본 제품

상담에서 매장 규모를 들으면 포스(N250)·테이블오더로 자연 확장. 객단가·마진이 큰 제품으로 연결.

즉 토스·네이버단말기 = 미끼이자 입구, 포스·테이블오더 = 본 매출. 광고는 입구(싼 키워드)에 쓰고, 본 매출은 상담에서 만든다 — 이게 누리에게 가장 ROI 높은 구조입니다.

최종 결론
1. 광고 예산은 토스·네이버(·카드)단말기에 집중 — 체결당 17~67만원, 가성비 압도적.
2. 포스기·테이블오더는 직접 광고로 1~2위 추격 금지(체결당 350만~1,100만). 포스기는 간판용 3~4위만, 테이블오더는 상담에서 제안.
3. 유입은 싸게, 매출은 상담에서 — 단말기로 들어온 사장님에게 전 라인업 교차 제안.
4. 월 50~100만 소액 테스트 → 전환추적으로 실제 상담·체결율 확인 → ROI 맞으면 확대. (지금 숫자는 가정 기반 추정)
