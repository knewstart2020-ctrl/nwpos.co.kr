1. 캠페인 구조 — 광고그룹 5개

전무님 배분(단말기 250만 / 포스 180만 / 빈틈 70만)은 유지하되, 고CPC 키워드가 그룹 예산을 독식하지 않도록 광고그룹을 5개로 분할했습니다. 캠페인 일예산은 그룹 합계(165,000)보다 9% 여유를 둬 골든타임 노출 손실을 막습니다.

5. 타게팅 (요일 · 시간 · 지역 · 디바이스)

⏰ 요일 · 시간대 (수동 설정)

  • 요일 월~금 100% / 토 90% / 일 70%
  • 08–11시 +110% 골든 (오픈준비·전일 마감후 탐색)
  • 11–14시 80% (점심 피크, 매장 바쁨)
  • 14–17시 +110% 골든 (브레이크타임 상담 양호)
  • 17–21시 90% / 21–24시 100% (마감후 정산·탐색)
  • 00–08시 50%↓ (무효클릭·정보성 방어)

📍 지역 · 디바이스

  • 지역 전국 노출 유지 + 수도권 가중
  • 강서·영등포·구로·양천·마포·부천·김포·인천 +20~30%
  • 비수도권 70~80%↓ (직영 AS 불가 지역)
  • 카드·토스단말기(전국형 고CPC)는 비수도권 50%↓
  • 디바이스 모바일 +110~120% (현장 즉시검색·전화상담), PC 100%
입찰 정책: 초기 4~6주 전 키워드 수동입찰(자동입찰은 데이터 부족 시 고CPC 위험). 주 2~3회 순위 점검, 밀리면 1회 +5~10% 상향하되 키워드별 목표CPC(실차감 추정×1.1배) 초과 시 순위 양보. 4주 후 전환 확보 키워드만 자동입찰(전환수 최대화) 전환 검토.

7. 운영 로드맵 + 2단계 정량 트리거

11단계 (1~4주) — 데이터 수집

위 5개 그룹 가동. 키워드별 클릭·CPC·전환(상담/전화) 실측. 빈틈(네이버주문) 저가 선점. 주간 루틴 — 월: 전주 성과 리뷰+입찰 조정 / 수: 소진·순위 점검 / 금: 검색어 리포트+부정키워드 추가+주말 가중.

22단계 (4주 후) — 정량 기준으로 재배분

  • 승격·증액 : 키워드별 전환 ≥ 3건 AND CPA ≤ 15만원 AND 클릭 ≥ 30 → 본 그룹 승격·입찰 상향
  • 하향·중단 : 클릭 ≥ 30인데 전환 0 → 입찰 하향 또는 일시정지
  • 테이블오더 정밀진입 : 단말기·포스 CPA가 목표 이하 안정 시, 테이블오더가격을 일 5,000원 초소액·지역한정으로 진입 → 전환 1건이라도 나오면 확대 판단(객단가 큼)
