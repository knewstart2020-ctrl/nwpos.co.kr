🎯 핵심 전략 요약 (Executive Summary)

프로모션 성격 한 줄 — SMT는 설치 일시금(특별 8만 + 누적티어)을 키우고 유지수수료(월한도 1만→5천, 반토막)를 깎았습니다. 즉 잔존수익에 기대지 말고 9/30 마감 전 "설치 물량"으로 승부하는 국면입니다.

  • 대당 수익: 1,000대(누적 3,000 미달) = 대당 13.5~14.5만원(총 1.35~1.45억) · 3,000대 티어 달성 = 대당 15.5만원(총 4.65억).
  • ⭐ 권고: 목표를 "1,000대(안전)"보다 "3,000대 티어 도전(전 직원)"으로 상향할 때 ROI가 급등 — 티어 보너스(3,000만)가 유지수익 손실을 크게 상회.
  • 1차 관문 = 유효 DB × 문자 응답률: 기본안(응답 4%·상담→설치 40%)으로 1,000대에 문자 발송 약 6.25만건 = 유효 가맹점 DB 6만+ 필요. → "유선카드단말기 설치 매장" DB 규모가 목표 상한을 결정.
  • 병목은 인력이 아님: 문서/가입팀 27건/일·자가설치팀 72건/일 처리 여유(필요 16대/일). 진짜 병목 = DB 규모 + 자가설치 완주율(중도포기 방지).
  • 실행 퍼널: 유선카드단말기 매장 세그 → (광고)문자(원고 3안 준비완료) → 문자상담 접수(전화대기 회피) → 우선 자가설치(원격지원) + 서류·네이버 가입. DB추출·발송 = MCP서버2 협조.
  • ⚠️ 컴플라이언스(정보통신망법): (광고) 머리표기 · 야간(21~08시) 발송금지 · 080 무료수신거부 · 기존거래 가맹점 수신동의 예외 근거 확보 — 위반 시 과태료.
ℹ️ 이 리포트는 1차 전략안입니다. 아래 각 섹션 끝 "확정 필요"의 값(특히 유선카드단말기 매장 DB 규모·대당 수익 실제 구성·수신동의 근거)이 채워지면 목표·발송량·손익이 정밀해집니다. 전무님 추가 정보 반영해 갱신 예정.

✅ 즉시 착수 가능한 다음 스텝

  1. MCP서버2 협조 요청 — "유선카드단말기 설치 매장" 세그먼트 DB 건수 산출 + (광고)문자 발송 캐파·수신동의 상태 확인.
  2. 파일럿 발송(소량 500~1,000건)로 응답률·상담전환 실측 → 원고 3안 A/B → 퍼널 가정(4%·40%)을 실값으로 교체.
  3. 자가설치 원격지원 키트(단계 영상·QR·FAQ) + 서류/네이버 가입 온라인 접수폼 제작 → 접수→설치 파이프라인(일정보고시스템) 세팅.
  4. 목표 재설정 결정 — 1,000대(안전) vs 3,000대 티어 도전(ROI 급등). 전무 확정.

⚠️ 실제 문자 발송·가맹 계약·설치는 전무 확인 및 컴플라이언스 충족 후 진행합니다.
