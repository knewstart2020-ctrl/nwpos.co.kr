🔑 STEP 1 · YouTube OAuth 발급 (5분, 1회만)

1

Google Cloud Console 접속

https://console.cloud.google.com/ 접속 → knewstart2020@gmail.com으로 로그인

2

새 프로젝트 생성

  • 상단 좌측 프로젝트 선택 → "새 프로젝트"
  • 프로젝트 이름: nwpos-publish
  • "만들기" 클릭
3

YouTube Data API v3 활성화

  • 좌측 메뉴 → API 및 서비스 → 라이브러리
  • 검색창에 YouTube Data API v3 입력
  • 해당 카드 클릭 → "사용" 버튼 클릭
4

OAuth 동의 화면 설정

  • 좌측 메뉴 → API 및 서비스 → OAuth 동의 화면
  • 사용자 유형: 외부(External) → 만들기
  • 앱 이름: 누리네트웍스 자동발행
  • 사용자 지원 이메일: knewstart2020@gmail.com
  • 개발자 연락처: knewstart2020@gmail.com
  • 저장 후 계속 → 범위 추가:
    • .../auth/youtube.upload (영상 업로드)
    • .../auth/youtube.readonly (영상 정보 조회)
  • 테스트 사용자 추가: knewstart2020@gmail.com
  • 저장
5

OAuth 클라이언트 ID 생성

  • 좌측 메뉴 → API 및 서비스 → 사용자 인증 정보
  • "+ 사용자 인증 정보 만들기" → OAuth 클라이언트 ID
  • 애플리케이션 유형: 데스크톱 앱
  • 이름: nwpos-desktop
  • "만들기" → 다이얼로그에서 JSON 다운로드 클릭
6

JSON 파일 저장

다운로드된 JSON 파일을 다음 경로에 정확히 저장:

C:\Users\knews\.nwpos\secrets\youtube-oauth-client.json
⚠️ 폴더가 없으면 자동 생성됨. 파일명도 정확히 youtube-oauth-client.json이어야 함.
7

최초 OAuth 동의 (브라우저 자동 열림)

Claude Code 세션에서 다음 1줄 실행 요청:

"유튜브 OAuth 토큰 발급해줘"

→ Claude Code가 python -c "from youtube_uploader import init_token; init_token()" 실행 → 브라우저 자동 열림 → Google 계정 선택 → "계속" → "허용" → 완료 메시지

✅ 토큰이 youtube-token.json에 저장됨. 이후 자동 갱신되므로 다시 동의할 필요 없음.

🆘 문제 해결

YouTube OAuth 안 됨

  • 403 access_denied: OAuth 동의 화면에서 테스트 사용자에 본인 이메일 추가 확인
  • quota exceeded: 하루 6 영상 업로드 한도. 다음날 재시도 또는 quota 승급 신청
  • 토큰 만료: youtube-token.json 삭제 후 STEP 1-7 다시 실행

네이버블로그 발행 실패

  • 로그인 풀림: Chrome에서 네이버 재로그인 → 로그인 유지 체크
  • SmartEditor iframe 진입 실패: Chrome 캐시 삭제 후 재시도
  • 스팸 차단: 24시간 간격 발행 권장
