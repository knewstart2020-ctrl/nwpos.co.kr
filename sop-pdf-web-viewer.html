PDF·문서 웹뷰어 표준 작업지침

누리네트웍스 · 2026-05-22 제정 · 모든 Claude 세션 공통 적용
핵심: 견적서·계약서·카탈로그 등 PDF·이미지 첨부 → ASCII 파일명 복사 + 브랜드 HTML 뷰어 페이지 + noindex + GitHub Pages URL 5단계로 자동 배포. 거래처·고객에게 URL 한 줄로 즉시 공유.

🎯 왜 이 SOP가 필요한가

  1. PDF 파일은 카톡·문자 첨부 시 용량 제한이 있고, 받는 사람이 다운로드 후 열어야 해서 불편
  2. URL 한 줄로 거래처·고객에게 즉시 견적·자료 공유 가능
  3. 모바일에서 PDF 뷰어 앱 없이도 브라우저 내 미리보기 지원
  4. URL은 유지하면서 PDF만 교체해서 자동 업데이트 가능
  5. 누리네트웍스 브랜드 헤더로 신뢰감 부여

✅ 5단계 표준 워크플로

1

원본 파일 ASCII 이름으로 복사

  • 위치: 홈페이지종합\nwpos.co.kr\<파일명>.pdf
  • 한글 파일명 금지 (GitHub Pages URL encoding 이슈)
  • 파일명 표준은 아래 표 참조
2

HTML 뷰어 페이지 생성

  • 위치: 홈페이지종합\nwpos.co.kr\<파일명>.html (PDF와 같은 파일명, 확장자만 .html)
  • 핵심 구성:
    • 누리네트웍스 브랜드 헤더 (네이비 그라데이션 + 골드 버튼)
    • PDF 미리보기 영역 (<object> + <iframe> 폴백)
    • 다운로드 버튼(<a download>) + 새 창 열기 버튼(target="_blank")
    • 비공개 배너 + 모바일 반응형
3

noindex 메타 + 비공개 배너 (내부 문서)

<meta name="robots" content="noindex, nofollow, noarchive, nosnippet">
<meta name="googlebot" content="noindex, nofollow">
<meta name="referrer" content="no-referrer">
<title>[내부용] {문서명} — 누리네트웍스</title>
4

GitHub Pages 배포

cd "C:\Users\knews\GoogleDrive\A.누리네트웍스업무폴더\홈페이지종합\nwpos.co.kr"
git add <파일명>.pdf <파일명>.html
git commit -m "Add internal document: <문서명> (noindex viewer)"
git push origin main
  • 1~5분 후 자동 게시
  • 두 URL 모두 발급:
    • 웹 뷰어: https://nwpos.co.kr/<파일명>.html
    • PDF 직접: https://nwpos.co.kr/<파일명>.pdf
5

NaverWorks 알림 + 사용자에게 URL 전달

📋 파일명 표준

용도파일명 패턴예시

📦 HTML 뷰어 표준 템플릿 (핵심)

<object data="{파일명}.pdf#view=FitH" type="application/pdf" class="pdf-frame">
  <iframe src="{파일명}.pdf#view=FitH" class="pdf-frame" frameborder="0">
    <p>브라우저에서 PDF 표시 불가.
      <a href="{파일명}.pdf">PDF 다운로드</a>
    </p>
  </iframe>
</object>

전체 템플릿: 메모리 파일 policy_pdf_web_viewer.md 참조 또는 기존 게시본 복사 (POS 견적서 · 키오스크 견적서)

🖼️ 이미지 문서일 경우

PDF 대신 JPG·PNG 스캔본인 경우:

  • <object>/<iframe> 대신 <img> 사용
  • 다운로드 버튼 동일 유지
  • 줌·회전 컨트롤 옵션 추가 가능

📦 다수 PDF 묶음

여러 PDF를 한 페이지에서 보여줄 경우:

  • 파일명: package-{프로젝트}-YYYY-MM-DD.html
  • 탭 UI 또는 카드 그리드로 PDF 목록 표시
  • 각 PDF는 개별 quote-XXX.pdf로 별도 저장 (재사용성)

🚨 주의사항

⚠️ 개인정보(주민번호·계좌번호 등) 포함 PDF는 게시 금지 — 사용자에게 마스킹 요청
  • 재무·민감정보 포함 PDF: noindex만으로 부족할 수 있음 → 사용자에게 게시 가능 여부 재확인
  • 외부 협력사 견적서: 사용자 사전 승인 후에만 게시
  • PDF 용량 10MB 초과: GitHub Pages가 느려질 수 있음 → 사용자에게 분할 또는 압축 제안
