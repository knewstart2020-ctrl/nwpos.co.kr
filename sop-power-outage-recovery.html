⚡ 정전 후 사무실 장비 복구 매뉴얼

제정 2026-09-02 · 근거: 2026-09-01 정전 실사고 복구 기록 · 누리네트웍스
정전으로 공유기가 재시작되면 장비들의 네트워크 주소 배정이 리셋됩니다. NAS(Y:드라이브)·프린터가 안 되는 것은 대부분 이 때문이며, 장비 고장이 아닙니다. 2026-09-02부로 NAS와 프린터에 고정 주소 예약을 걸어 재발을 막았습니다 — 남는 것은 아래 직원 확인 2가지뿐입니다.

1부 · 전 직원 — 정전 복구 후 확인 2가지 (1분이면 끝)

1프린터 전원을 손으로 켜세요
  • Kyocera 프린터는 정전 후 자동으로 다시 켜지지 않습니다.
  • 전원 램프가 꺼져 있으면 본체 전원 버튼을 누르고 1~2분 기다립니다.
  • 프린터가 물린 멀티탭 스위치도 함께 확인하세요.
  • 인쇄 대기 중이던 문서는 살아나면 자동 출력됩니다. 안 나오면 그 문서만 삭제 후 다시 인쇄.
2NAS(Y: 드라이브)는 2~3분 기다린 뒤 재시도
  • NAS는 자동으로 다시 켜지지만 부팅에 2~3분 걸립니다.
  • Y: 드라이브가 안 열리면 잠시 후 다시 시도 → 그래도 안 되면 관리자에게 알려주세요.

2부 · 관리자 — 복구 절차 (장애가 계속될 때)

장비 고정 주소표

장비고정 IPMAC서비스
Synology NAS (SM_NURI)192.168.0.300-11-32-AC-62-DA (활성 LAN1)
…-62-DB (예비 LAN2)		DSM :5000 · WebDAV(Y:) :5006 · 파일공유 :445
Kyocera ECOSYS PA3500cx192.168.0.14D4-F0-C9-26-45-8F인쇄 :9100
공유기 ipTIME T3008192.168.0.1—관리화면 http://192.168.0.1

절차

  1. 실태 파악 — 명령 프롬프트에서 ping 192.168.0.3 / ping 192.168.0.14. 응답이 있어도 arp -a로 MAC이 위 표와 일치하는지 확인. 다르면 다른 기기가 주소를 차지한 것입니다(MAC 두 번째 자리가 2·6·A·E면 휴대폰류 랜덤 주소).
  2. 공유기 고정 예약 확인 — http://192.168.0.1 → 고급설정 → 네트워크관리 → DHCP 서버 설정
    • 「등록된 주소 관리」에 NAS(.3)·프린터(.14) 두 줄이 있는지 확인
    • 없으면 「수동 주소 입력」에 IP+MAC 입력 → [수동 등록] → [적용] → 우측 상단 [저장]
    • 원래 주소를 다른 기기가 차지했으면 그 줄 체크 → [삭제] (휴대폰이면 Wi-Fi 껐다 켜기)
  3. 장비 재시작 — 새 예약 주소를 받게:
    • NAS: 현재 IP의 DSM(:5000) 접속 → 재시작 (또는 본체 전원 버튼)
    • 프린터: 전원 껐다 켜기
  4. 확인 — ping 응답 + Y: 드라이브 열기 + 시험 인쇄
⚠️ 흔한 함정
  • 「연결 거부」 오류인데 핑은 되는 경우 = 다른 기기가 그 주소를 차지한 것 (장비 고장 아님)
  • NAS는 LAN 포트가 2개(MAC 끝 DA/DB) — MAC 확인 시 둘 다 NAS입니다
  • 프린터 「오프라인」은 대부분 본체 전원 꺼짐이 먼저입니다 — 네트워크보다 전원부터 확인

예방 체크리스트 (분기 1회 점검)

  • 공유기 「등록된 주소 관리」에 NAS(.3)·프린터(.14) 예약 유지
  • NAS DSM → 제어판 → 하드웨어 및 전원 → 「정전 후 자동 재시작」 켜짐
  • 공유기·NAS는 가능하면 UPS(무정전 전원장치) 연결 검토

부록 · 2026-09-01 정전 실사고 기록

  • 9/1 밤 정전 → 공유기 재시작으로 주소 배정 리셋
  • 휴대폰이 NAS 자리(.3)를 선점 → NAS가 .2로 밀림 → 전 직원 Y: 드라이브 불통
  • 프린터는 본체가 꺼진 채였고, 켜니 새 주소(.32)를 받음 → 전 PC 「오프라인」
  • 복구: 공유기 고정 예약(NAS .3, 프린터 .14) 등록 + 장비 재시작 → 원상 복귀
  • 데이터 손상 없음 (NAS 볼륨 정상 확인)
