보고서 HTML 웹발행 표준 작업지침

누리네트웍스 · 2026-05-22 제정 · 모든 Claude 세션 공통 적용
핵심: 모든 보고서는 ① MD 원본 + ② 브랜드 HTML + ③ noindex 비공개 + ④ GitHub Pages URL 4단계로 자동 배포. CEO·임원·협력사에게 URL 한 줄로 즉시 공유.

🎯 왜 이 SOP가 필요한가

  1. 사용자 PC 환경에서 MD·TXT 파일 더블클릭으로 안 열린다 (이전 12회 시행착오 확인)
  2. CEO·임원·외부 협력사에게 카톡·문자·이메일로 URL 한 줄만 보내면 PC·모바일 어디서나 즉시 열람
  3. 인쇄 시 자동 정리 레이아웃 → 종이 보고도 그대로 사용
  4. URL이므로 수정·재배포 즉시 반영 (재발송 불필요)

✅ 4단계 표준 워크플로

1

MD 원본 작성

  • 위치: 홈페이지종합\<보고서명>.md
  • 용도: 내부 편집·버전 관리·다른 도구 호환
2

HTML 변환 (브랜드 톤)

  • 위치: 홈페이지종합\nwpos.co.kr\<보고서명>.html
  • 표준 디자인 토큰:
    • 네이비 #0A1A3A · 골드 #C9A961 · 블루 #0066FF · 페이퍼 #F7F4ED
    • 폰트: Noto Sans KR (헤딩 weight 800, 본문 400)
    • 본문 max-width: 880px (가독성)
  • 인쇄 CSS 필수: @media print { ... }
  • 표지 배너 (네이비 그라데이션 + 작성일 + 핵심 요약 박스)
3

비공개 메타 태그 (내부 보고서)

HTML <head> 안에 반드시 포함:

<meta name="robots" content="noindex, nofollow, noarchive, nosnippet">
<meta name="googlebot" content="noindex, nofollow">
<meta name="referrer" content="no-referrer">
<title>[내부용] {보고서명}</title>

body 최상단에 빨간색 비공개 배너 (위의 빨간 박스와 같은 형태)

4

GitHub Pages 배포

cd "C:\Users\knews\GoogleDrive\A.누리네트웍스업무폴더\홈페이지종합\nwpos.co.kr"
git add <보고서명>.html
git commit -m "Add internal report (noindex)"
git push origin main
  • 1~5분 후 자동 게시
  • URL 형식: https://nwpos.co.kr/<보고서명>.html
  • HTTP 200 확인 후 사용자에게 전달

🔐 git config (이 PC 한정 주의사항)

이 PC(knews@Nuri2012)는 git 글로벌 user.email/name이 비어 있어 commit이 실패한다. 반드시 로컬 repo에 한정으로 설정: 
git config user.email "knewstart2020@gmail.com"
git config user.name "knewstart2020-ctrl"

⚠️ --global 절대 사용 금지. 사용자 시스템 설정을 변경할 권한이 없다.
